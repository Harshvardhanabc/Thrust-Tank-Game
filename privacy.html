Privacy

ECHOBOUND stores your game progress (best score, run counts, unlocks) only in your own browser using localStorage. No account is required, and the game itself does not send any personal information anywhere. You can erase the saved data at any time with "Reset progress" on the main menu or by clearing your browser's site data.

The share button only creates an image or text on your device when you press it. Nothing is posted automatically.

Scope: this statement covers only the game as implemented here. It must be updated if analytics, advertising, external services or any data collection are added later.
